# 电力安全事故法律责任与罚则

## R — 原文（Reading）

> 对事故责任单位，由国务院能源主管部门或者派出能源监管机构依照下列规定处以罚款：（一）发生一般事故的，处30万元以上100万元以下的罚款；（二）发生较大事故的，处100万元以上200万元以下的罚款；（三）发生重大事故的，处200万元以上1000万元以下的罚款；（四）发生特别重大事故的，处1000万元以上2000万元以下的罚款。事故情节特别严重、影响特别恶劣的，可以按照前款罚款数额的2倍以上5倍以下处以罚款。
>
> — 国务院《电力安全事故应急处置和调查处理条例》第29条

> 事故发生单位主要负责人依照本条例规定受到撤职及以上处分或者刑事处罚的，自受处分之日或者刑罚执行完毕之日起5年内，不得担任任何生产经营单位主要负责人。
>
> — 第31条

---

## I — 方法论骨架（Interpretation）

罚则是"行为红线 + 金额矩阵 + 个人追责 + 从业禁止"四层：

1. **行为红线（失败模式）**（第27–28条）：不立即处置、迟报、擅离职守；谎报瞒报、伪造破坏现场、转移隐匿销毁证据、拒绝调查/提供资料、作伪证、逃匿——这些本身即重罚事由。
2. **单位罚款矩阵**（第29条，按事故等级）：一般 30–100万 / 较大 100–200万 / 重大 200–1000万 / 特别重大 1000–2000万；情节特别恶劣处 2–5 倍。
3. **个人罚款**（第30条）：主要负责人按上年收入——一般 40% / 较大 60% / 重大 80% / 特别重大 100%；其他负责人与安全管理人员 20%–50%。
4. **主要负责人失职罚款**（第27条）：不立即处置/迟报/擅离职守，罚上年收入 60%–100%。
5. **从业禁止**（第31条）：受撤职及以上处分或刑罚者，5 年内不得担任任何生产经营单位主要负责人。
6. **公职与调查人员责任**（第32–34条）：政府部门、调度机构、调查人员失职/干涉/包庇/打击报复，依法给予处分，构成犯罪的追刑责。

## A1 — 书中的应用（Past Application）

### 案例 1：按等级罚单位
- **问题**: 发生特别重大事故。
- **方法论使用**: 第29条：单位罚 1000–2000 万；情节特别恶劣处 2–5 倍（即最高 1 亿）。
- **结论**: 顶格区间。
- **结果**: 由能源主管部门/派出机构处罚。

### 案例 2：瞒报 + 个人追责
- **问题**: 单位瞒报事故、主要负责人逃匿。
- **方法论使用**: 第28条：单位罚 100–500 万，主要及直接责任人员罚上年收入 60%–100%；第31条：若受撤职/刑罚，5 年禁任。
- **结论**: 单位 + 个人双罚 + 可能的从业禁止。
- **结果**: 多重追责叠加。

- "一般/较大/重大/特别重大事故单位罚款区间"

- 与 `power-accident-reporting`：reporting 列"红线"，本 skill 列"红线后果"。

## E — 可执行步骤（Execution）

1. **识别行为性质**
   - 完成标准：区分是"等级事故罚款"（第29–30条）还是"禁止行为罚款"（第27–28条瞒报/伪造/逃匿等）。
2. **按等级取单位罚款**
   - 完成标准：一般 30–100万 / 较大 100–200万 / 重大 200–1000万 / 特别重大 1000–2000万；情节特别恶劣 ×2–5。
3. **计算个人罚款**
   - 完成标准：主要负责人按等级 40%/60%/80%/100%；其他负责人与安管 20%–50%；失职（不处置/迟报/擅离）60%–100%。
4. **判定从业禁止与公职责任**
   - 完成标准：撤职/刑罚者 5 年禁任（第31条）；公职/调度/调查人员失职干涉包庇追处分与刑责（第32–34条）。

## B — 边界（Boundary）★

### 不要在以下情况使用此 skill
- 需定级 → 转 `power-accident-grade-classify`（等级是罚款输入）。
- 需定"向谁报告/怎么处置/谁调查" → 转对应 skill。

### 作者在书中警告的失败模式
- 瞒报、谎报、伪造或故意破坏现场、转移隐匿资金财产、销毁证据、拒绝调查、作伪证、事故发生后逃匿（第28条）。
- 主要负责人不立即处置、迟报、擅离职守（第27条）。
- 政府部门/调度机构/调查人员阻挠调查、重大疏漏、包庇打击报复（第32–34条）。

### 作者的盲点 / 时代局限
- 罚款以"事故等级"为锚，但等级判定本身存在单一供电区域标准"另行制定"的空档（第3条），可能影响罚基确定。

### 容易混淆的邻近方法论
- 与《生产安全事故报告和调查处理条例》罚款标准不同；同一事件若双轨，注意衔接（第35条）。
