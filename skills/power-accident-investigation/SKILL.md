# 电力安全事故调查处理

## R — 原文（Reading）

> 特别重大事故由国务院或者国务院授权的部门组织事故调查组进行调查。重大事故由国务院能源主管部门组织事故调查组进行调查。较大事故、一般事故由派出能源监管机构组织事故调查组进行调查。国务院能源主管部门认为必要的，可以组织事故调查组对较大事故进行调查。未造成供电用户停电的一般事故，派出能源监管机构也可以委托事故发生单位调查处理。
>
> — 国务院《电力安全事故应急处置和调查处理条例》第21条

> 事故调查组应当在下列期限内向组织事故调查组的机关提交事故调查报告：（一）特别重大事故和重大事故的调查期限为60日；…（二）较大事故和一般事故的调查期限为45日；…事故调查期限自事故发生之日起计算。
>
> — 第23条

---

## I — 方法论骨架（Interpretation）

调查是一个"权限—组成—期限—报告—批复—评估"的闭环：

1. **管辖权限按等级分配**（第21条）：特别重大→国务院或其授权部门；重大→能源主管部门；较大/一般→派出机构（能源主管部门可提级调查较大事故）；未造成用户停电的一般事故可委托事故发生单位调查。
2. **调查组组成**（第22条）：有关政府及能源/应急管理等部门 + 消防救援机构；邀请公安、检察院；及时通报并邀请监察机关介入；可聘专家；组长由组织机关指定。
3. **期限**（第23条）：特别重大/重大 60 日（可延长≤60日）；较大/一般 45 日（可延长≤45日）；自事故发生日起算。
4. **报告六要素**（第24条）：单位情况与经过、直接损失与影响、原因与性质、应急处置与恢复情况、责任认定与处理建议（含追责公职人员名单）、防范整改措施；附证据与技术分析；成员签字。
5. **批复与执行**（第25条）：报告经组织机关批复即结束；委托调查的一般事故报派出机构批复；依法公布；机关处罚、公职人员处分；单位处理并报结果。
6. **整改评估**（第26条）：批复后一年内，能源主管部门/派出机构组织防范整改措施落实评估并公开。

## A1 — 书中的应用（Past Application）

### 案例 1：管辖判定
- **问题**: 一起较大事故发生在某省。
- **方法论使用**: 依第21条，较大事故由派出能源监管机构组织调查；若能源主管部门认为必要可提级。
- **结论**: 派出机构牵头。
- **结果**: 明确调查主体。

### 案例 2：期限与报告
- **问题**: 一般事故调查需多久、报告写什么。
- **方法论使用**: 依第23条 45 日（可延≤45日）；依第24条六要素 + 成员签字 + 附技术分析。
- **结论**: 合规闭环。
- **结果**: 报告批复后一年内评估整改（第26条）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个 skill？
1. 事故定级后需确定调查主体与时限。
2. 编制调查配合清单、准备调查报告模板。
3. 跟踪整改评估与处罚执行。

### 语言信号
- "这起事故由谁调查 / 派出机构还是能源主管部门"
- "调查组由哪些部门组成 / 调查期限多少天"
- "调查报告要写什么 / 整改怎么评估"

### 与相邻 skill 的区分
- 与 `power-accident-grade-classify`：本 skill 据等级决定"谁调查"，不判定等级。
- 与 `power-accident-reporting`：报告在前，调查在后。
- 与 `power-accident-liability-penalty`：本 skill 出"责任认定与处理建议"，penalty 落地"罚款金额"。

## E — 可执行步骤（Execution）

1. **确定调查主体**
   - 完成标准：按第21条依等级锁定（特别重大→国务院；重大→能源主管部门；较大/一般→派出机构；必要可提级；未停电一般事故可委托单位）。
2. **组建调查组**
   - 完成标准：列明政府及能源/应急/消防等部门 + 公安/检察院 + 监察机关介入 + 可聘专家；组长由组织机关指定（第22条）。
3. **把控期限**
   - 完成标准：特别重大/重大 60 日、较大/一般 45 日（可延≤原期限），自事故发生日起算（第23条）。
4. **形成并批复报告**
   - 完成标准：六要素齐全 + 成员签字 + 附证据技术分析；报组织机关批复；依法公布（第24–25条）。
5. **跟踪整改评估**
   - 完成标准：批复后一年内组织防范整改措施评估并公开（第26条）。

## B — 边界（Boundary）★

### 不要在以下情况使用此 skill
- 需定级 → 转 `power-accident-grade-classify`。
- 需定"向谁报告" → 转 `power-accident-reporting`。
- 仅问罚款金额 → 转 `power-accident-liability-penalty`。

### 作者在书中警告的失败模式
- 政府部门阻碍、干涉事故调查，或在调查中作伪证、指使作伪证（第32条）。
- 调查人员重大疏漏、包庇袒护或借机打击报复（第34条）。
- 调度机构不配合调查、拒绝提供资料、销毁证据（第33条）。

### 作者的盲点 / 时代局限
- 第35条与《生产安全事故报告和调查处理条例》"等级不同按较高者"的衔接，可能导致同一事件双轨调查，增加合规成本。

### 容易混淆的邻近方法论
- 与"报告"不同：报告走 `power-accident-reporting`；与"罚则"不同：走 `power-accident-liability-penalty`。
