# 电力安全事故报告流程

## R — 原文（Reading）

> 事故发生后，事故现场有关人员应当立即向发电厂、变电（换流）站运行值班人员，电力调度机构值班人员或者本单位现场负责人报告。有关人员接到报告后，应当立即向上一级电力调度机构和本单位负责人报告。本单位负责人接到报告后应当立即向国务院能源主管部门设在当地的派出机构、县级以上人民政府应急管理部门报告。
>
> — 国务院《电力安全事故应急处置和调查处理条例》第8条

> 事故报告应当包括下列内容：（一）事故发生的时间、地点、单位及简要经过；（二）设备设施损坏、停运设备数量、减供负荷或停电范围；（三）原因初步判断；（四）已采取措施、电网运行方式及控制情况；（五）其他应报告情况。可以先行报告已知情况，后续再报详细情况。
>
> — 第10条

---

## I — 方法论骨架（Interpretation）

报告是一个**逐级、即时、可补报**的链条，核心规则：

1. **现场即时报**：现场人员→发电厂/变电站值班、调度值班或现场负责人（"立即"）。
2. **二级上行**：接报人→上一级调度机构 + 本单位负责人；本单位负责人→派出能源监管机构 + 县级以上应急管理部门。
3. **加报分支**：热电厂影响供热→加报供热管理部门；水电厂大坝安全→加报水行政主管部门/流域机构；造成用户停电→派出机构同时通报县级以上地方政府。
4. **上行直报**：省级及以上调度直报能源主管部门/派出机构；特别重大/重大由能源主管部门直报国务院。
5. **内容五要素**（第10条），可"先报已知、后报详细"，新情况及时补报。
6. **红线**：不得迟报、瞒报、谎报；不得阻挠干涉报告与调查（第7、19条）。

## A1 — 书中的应用（Past Application）

### 案例 1：常规链条
- **问题**: 某变电站事故，现场人员发现。
- **方法论使用**: 现场→变电站值班/调度值班/现场负责人（立即）→上一级调度+本单位负责人→派出机构+县级应急管理部门。
- **结论**: 形成完整逐级记录。
- **结果**: 满足第8条时效与路径要求。

### 案例 2：加报分支
- **问题**: 热电厂事故同时影响热力供应。
- **方法论使用**: 在常规链条外，加报供热管理部门（第8条）。
- **结论**: 避免遗漏法定接收方。
- **结果**: 防止"漏报专管部门"的合规风险。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个 skill？
1. 事故刚发生，现场/值班人员不清楚"第一报给谁"。
2. 编制事故报告模板或演练脚本，需固化五要素与路径。
3. 收到"能否先报概要、后续补报"或"迟报后果"的问询。

### 语言信号
- "事故发生了该先报谁 / 报给派出机构还是应急管理局"
- "报告内容要写哪些 / 能不能先报已知的"
- "热电厂事故还要报供热部门吗 / 迟报瞒报会怎样"

### 与相邻 skill 的区分
- 与 `power-accident-grade-classify`：本 skill 不判定等级，只管"报告动作"。
- 与 `power-accident-emergency-response`：报告是处置的前置动作，处置要点由后者承接。
- 与 `power-accident-liability-penalty`：迟报瞒报的"后果"由 penalty 给出，本 skill 只列"红线"。

## E — 可执行步骤（Execution）

1. **启动现场即时报告**
   - 完成标准：现场人员已在"立即"内报至值班/调度/现场负责人。
2. **构建逐级上行路径**
   - 完成标准：明确"上一级调度 + 本单位负责人 → 派出机构 + 县级应急管理部门"两跳。
   - 判停条件：若涉热电厂供热/水电大坝，追加对应专管部门（第8条）。
3. **填写五要素报告**
   - 完成标准：时间地点单位经过、设备损停与减供/停电范围、原因初判、已采取的措施与电网方式、其他 → 五项齐全；可先报已知。
4. **提示红线**
   - 完成标准：明确告知"不得迟报/瞒报/谎报、不得阻挠调查"（第7、19条）。

## B — 边界（Boundary）★

### 不要在以下情况使用此 skill
- 需判定事故等级 → 转 `power-accident-grade-classify`。
- 需决定"谁调查" → 转 `power-accident-investigation`。
- 仅咨询罚款金额 → 转 `power-accident-liability-penalty`。

### 作者在书中警告的失败模式
- 迟报、瞒报、谎报事故（第19、27–28条）。
- 阻挠和干涉对事故的报告与依法调查（第7条）。

### 作者的盲点 / 时代局限
- 条例强调"立即/及时"但未给分钟级硬性时限，实操中易以"尽快"代"立即"，建议企业内规进一步量化。

### 容易混淆的邻近方法论
- 与《生产安全事故报告和调查处理条例》的 1h/2h 报告时限不同；本条例未设统一小时数，以"立即"为准（第35条衔接）。
