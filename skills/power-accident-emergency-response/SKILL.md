# 电力安全事故应急处置

## R — 原文（Reading）

> 事故可能导致破坏电力系统稳定和电网大面积停电的，电力调度机构有权决定采取拉限负荷、解列电网、解列发电设备等必要措施。
>
> — 国务院《电力安全事故应急处置和调查处理条例》第14条

> 恢复电网运行和电力供应，应当优先保证重要发电厂厂用电源、重要输变电设备、电力主干网架的恢复，优先恢复重要电力用户、重要城市、重点地区的电力供应。
>
> — 第15条

---

## I — 方法论骨架（Interpretation）

处置以"防止系统性崩溃、尽快恢复"为目标，三层逻辑：

1. **事前准备**：电力企业制定应急救援预案并定期演练，报派出机构备案、抄报县级应急管理部门（第12条）。
2. **事中紧急处置**：有关主体立即控范围、防瓦解；危及人身设备安全时值班人员可立即停运发电/输变电设备；设备设施损坏立即抢修（第13条）。
3. **调度命令权**：调度机构可发启停机组、调整有功无功、调整运行方式等命令，各方必须执行；危及稳定/大面积停电时有权拉限负荷、解列电网/机组（第14条）；全停时立即定恢复方案、启动黑启动/孤网或外来电源（第14条）。
4. **恢复优先序**：先保重要厂用电、重要输变电设备、主干网架；再优先恢复重要用户、重要城市、重点地区（第15条）。
5. **大面积停电应急**：按预案启动响应、成立指挥机构、防次生灾害；地方政府做安保/排险/救治转移/交通通信/物资保障（第16–18条）；重要用户启自备电源，人员密集场所启应急照明疏散（第19条）。
6. **统一信息发布**：影响范围、处置进度、预计恢复时间由指挥机构/能源主管部门/派出机构统一准确及时发布（第20条）。

## A1 — 书中的应用（Past Application）

### 案例 1：调度机构拉限负荷
- **问题**: 某区域故障可能引发稳定破坏与大面积停电。
- **方法论使用**: 调度机构依第14条决定拉限负荷、解列部分电网/机组，防止系统性崩溃。
- **结论**: 行使紧急命令权。
- **结果**: 避免全网瓦解（各方必须执行调度命令）。

### 案例 2：恢复优先序
- **问题**: 事故后需恢复供电，资源有限。
- **方法论使用**: 依第15条先恢复重要厂用电、主干网架，再优先重要用户与城市。
- **结论**: 保关键、保重点。
- **结果**: 重要城市与重要用户先行复电。

## E — 可执行步骤（Execution）

1. **启动预案与紧急处置**
   - 完成标准：相关主体立即控范围、防瓦解；危及安全时值班人员可立即停运设备；损坏设备立即抢修。
2. **行使/执行调度命令权**
   - 完成标准：调度机构依第14条发启停/调整/解列命令，各方执行；全停时定恢复方案、启黑启动/孤网或外来电源。
   - 判停条件：若仅一般设备故障无瓦解风险，正常抢修即可，不触发拉限/解列。
3. **按优先序恢复**
   - 完成标准：先重要厂用电/主干网架，再重要用户/城市/重点地区。
4. **大面积停电与信息发布**
   - 完成标准：按预案启动响应、成立指挥机构；信息由指定机构统一发布（第16–20条）。

## B — 边界（Boundary）★

### 不要在以下情况使用此 skill
- 需定级 → 转 `power-accident-grade-classify`。
- 需定"向谁报告" → 转 `power-accident-reporting`。
- 仅问罚则 → 转 `power-accident-liability-penalty`。

### 作者在书中警告的失败模式
- 调度机构未及时处置致事故扩大、未及时恢复供电（第33条）。
- 不配合调查、拒绝提供资料、作伪证或销毁证据（第33条，属处置后调查阶段失败模式）。

### 作者的盲点 / 时代局限
- 第14条假设调度命令权在极端事故下无阻碍执行，但跨省/跨区协调实操阻力未充分展开；建议企业预案明确越权/越界协调机制。

### 容易混淆的邻近方法论
- 与处置"报告"动作不同：报告走 `power-accident-reporting`；与"调查追责"不同：走 `power-accident-investigation`。
