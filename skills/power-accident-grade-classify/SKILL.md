# 电力安全事故等级判定

## R — 原文（Reading）

> 根据电力安全事故影响电力系统安全稳定运行或者影响电力正常供应的程度，事故分为特别重大事故、重大事故、较大事故和一般事故。事故等级划分标准由本条例附表列示。
>
> — 国务院《电力安全事故应急处置和调查处理条例》第3条

> 符合本表所列情形之一的，即构成相应等级的电力安全事故。本表中所称的"以上"包括本数，"以下"不包括本数。
>
> — 附件《电力安全事故等级划分标准》注

---

## I — 方法论骨架（Interpretation）

定级不看伤亡或经济损失，只看"对系统/对用户的影响程度"。判定是一个**多维度取高**逻辑：

1. 收集事实：电网类型（区域性/省网/直辖市/省会城市/设区的市/县级市/其他县级）、事故发生起始时刻电网负荷、各维度实测值。
2. 五个判定维度任一命中即定级：①电网减供负荷比例 ②供电用户停电比例 ③发电厂或220kV以上变电站安全故障影响（电压偏离15%以上且持续1.5h以上）④发电出力下降致备用容量下降 ⑤发电设备安全故障停运超大修/小修两周且致减供负荷。
3. **取最高级**：五个维度中任一个达到更高级，即定为该更高级（"符合表中所列情形之一的，即构成相应等级"）。
4. 阈值随"电网类型 + 电网负荷档"细分，必须按对应档位查表，"以上含本数、以下不含本数"。
5. 单一输电线路/单一变电站供电区域另有专门标准（第3条），不套本表。

## A1 — 书中的应用（Past Application）

### 案例 1：省网减供负荷定级
- **问题**: 某省网起始负荷 10000MW（属 5000–11000MW 档），事故减供 6000MW。
- **方法论使用**: 减供比例 = 6000/10000 = 60%，查省网 5000–11000MW 档"减供负荷 50% 以上 → 特别重大"。
- **结论**: 特别重大事故。
- **结果**: 由国务院组织调查（见 `power-accident-investigation`）。

### 案例 2：变电站故障影响维度
- **问题**: 220kV以上变电站因安全故障，致周边 220kV以上运行母线电压偏离标称 18%、持续 2 小时。
- **方法论使用**: 命中"电压偏离 15% 以上且持续 1.5h 以上" → 一般事故（影响维度）。
- **结论**: 一般事故。
- **结果**: 由派出能源监管机构调查。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个 skill？
1. 事故发生后需要第一时间判断事件级别，以决定报告路径与调查层级。
2. 编制预案、演练或合规自查时，需要校准"什么情形算哪级"。
3. 收到监管问询或内部通报，需对事件定级发表意见。

### 语言信号
- "这起事故算几级 / 够不够特别重大"
- "减供负荷 X%、停电用户 Y%，按 845 号令附件怎么定级"
- "电网负荷 10000MW 减供 50% 是什么等级"

### 与相邻 skill 的区分
- 与 `power-accident-reporting`：本 skill 只回答"算哪级"，报告路径由 reporting 承接。
- 与 `power-accident-investigation`：本 skill 产出等级，investigation 据等级决定"谁调查"。
- 与 `power-accident-liability-penalty`：本 skill 产出等级，penalty 据等级决定"罚多少"。

## E — 可执行步骤（Execution）

1. **锁定电网类型与起始负荷**
   - 完成标准：明确是区域性/省网/直辖市/省会/设区的市/县级市/其他县级，及起始时刻实际负荷（MW）。
2. **按五个维度逐一排查**
   - 完成标准：对减供负荷比例、停电用户比例、变电站影响、出力下降、设备停运五个维度分别给出"是否命中及命中等级"。
   - 判停条件：若任一维度命中"特别重大"，直接定级特别重大，无需继续比对。
3. **取最高级并标注命中维度**
   - 完成标准：输出"建议等级 + 命中维度 + 对应阈值"。
4. **核查例外**
   - 完成标准：确认是否属"单一供电区域"（第3条另行标准）或"纯伤亡/经济损失"（第35条转生产安全事故条例）；若是则跳转对应 skill。

## B — 边界（Boundary）★

### 不要在以下情况使用此 skill
- 事件仅造成人员伤亡或直接经济损失、且不影响电力系统稳定运行与电力供应 → 转《生产安全事故报告和调查处理条例》（第35条、第118行）。
- 核电厂核事故 → 依《核电厂核事故应急管理条例》（第37条）。
- 纯法律条文咨询、不涉具体事件定级。

### 作者在书中警告的失败模式
- 把"电网减供负荷"误算为含用户主动脱网负荷（第141行：电压/频率波动期间用户出于自身安全主动脱网的不计入）。
- 单一故障扰动后仅造成单一供电大用户负荷损失，误计入电网减供（第142行：负荷占所在区域 10% 以上且单一供电的用户不计入）。
- 混淆"以上/以下"含 exclude 边界（"以上"含本数、"以下"不含本数）。

### 作者的盲点 / 时代局限
- 单一输电线路/单一变电站供电区域的等级标准"另行制定"（第3条），存在配套空档，定级时可能无现成阈值。

### 容易混淆的邻近方法论
- 与《生产安全事故报告和调查处理条例》的等级（按伤亡/损失）不同；同一事件两等级不同时"按较高者"（第35条）。
